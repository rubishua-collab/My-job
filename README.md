# יומן חשבון בוקר — אפליקציה

אפליקציית ווב בעברית (PWA) שמחליפה את התוכנה הקיימת. אפשר להתקין אותה במסך הבית באייפון ולפתוח אותה גם מהמחשב. שני המכשירים עובדים מול אותו מסד נתונים מאובטח בשרת.

## מה יש בה
- **היום**: כמה צפוי להיגבות, כמה נגבה בפועל, כמה נשאר ומי עדיין ממתין לאיסוף. לחיצה על סכום פותחת את הרשומות שמרכיבות אותו.
- **חשבון בוקר, פיצול, חשבון גובים, איסוף יום**: אותם חישובים בדיוק כמו בתוכנה המקורית. הקוד הועתק כמו שהוא, ראו `public/js/calc.js`.
- **שליחת וואטסאפ מרוכזת** דרך WhatsApp Business Platform הרשמית:
  - שליחה מצד השרת, בתבניות שאושרו על ידי Meta.
  - תיעוד הסכמה, וטיפול בבקשות הסרה (״הסר״).
  - סטטוס מסירה לפי ה-Webhook של Meta.
  - ניסיון חוזר רק להודעות שנכשלו.
- **כרטיס לקוח** עם כל ההיסטוריה. חיפוש לפי שם, טלפון, גובה, שליח ותאריך.
- **סימון איסוף**:
  - ההפרדה בין ״גובה אחראי״ לבין ״אסף בפועל״ נשמרת.
  - תיקון סימון שגוי מתועד: מי שינה, מתי, ומה היה לפני.
  - שליחת הודעה לא משנה יתרה.
- **הרשאות לפי תפקיד**:
  - בעלים: הכול.
  - מנהל: הכול חוץ מניהול משתמשים ושחזור גיבוי.
  - גובה: רק האיסופים שלו. לא רואה חוזים, תעודות זהות או נתונים כספיים.
- **שמירה בטוחה**:
  - כל פעולה מקבלת מזהה חד-פעמי, כך שניסיון חוזר אחרי בעיית קליטה לא רושם פעמיים.
  - כשהשמירה נכשלת מופיע פס אדום עם כפתור ״נסה שוב״.
- **גיבוי וייבוא**:
  - הורדת גיבוי מלא.
  - ייבוא חוזר של אותו גיבוי לא יוצר כפילויות.
  - דוח התאמה מציג לפני ואחרי.

## הפעלה מקומית
```bash
OWNER_USERNAME=owner OWNER_PASSWORD='סיסמה-חזקה' IMPORT_ON_START=/path/backup.json npm start
# http://localhost:8080
```
- דרישה: Node.js 22.5 ומעלה. אין תלויות חיצוניות, ומסד הנתונים הוא SQLite מובנה.
- הנתונים נשמרים בתיקייה `data/`, או בתיקייה שמוגדרת ב-`DATA_DIR`.

## פריסה לשרת (נדרש פעם אחת)
- **Render:** בחשבון Render בחרו New → Blueprint ואת המאגר הזה. הקובץ `render.yaml` מגדיר שרת עם דיסק קבוע.
- **כל שרת שמריץ Docker:** `docker run -p 8080:8080 -v yoman-data:/data -e ... <image>`.

משתני סביבה:

| משתנה | תפקיד |
|---|---|
| `PUBLIC_URL` | הכתובת הציבורית (https), לדוגמה `https://yoman.onrender.com` |
| `OWNER_USERNAME`, `OWNER_PASSWORD` | משתמש הבעלים הראשון. נוצר רק אם אין עדיין משתמשים |
| `WA_TOKEN` | אסימון System User קבוע עם `whatsapp_business_messaging` ו-`whatsapp_business_management` |
| `WA_PHONE_NUMBER_ID` | מזהה המספר העסקי |
| `WA_BUSINESS_ACCOUNT_ID` | מזהה חשבון הוואטסאפ העסקי (WABA) |
| `WA_APP_SECRET` | ה-App Secret של אפליקציית Meta, לאימות חתימת ה-Webhook |
| `WA_VERIFY_TOKEN` | מחרוזת שבוחרים ומזינים גם ב-Meta |
| `ANTHROPIC_API_KEY` | לא חובה. מפעיל קריאת תמונות (רשימות, ת״ז) ופקודה חופשית דרך Claude |
| `CONTRACTS_GAS_URL` | לא חובה. גיבוי חוזים חתומים ל-Google Drive דרך Apps Script |

ב-Meta: WhatsApp → Configuration → Webhook לכתובת `PUBLIC_URL/webhooks/whatsapp`, עם השדה `messages`.

## העברת הנתונים
1. בתוכנה הקיימת: ״חשבונות שמורים״ → ״גיבוי מלא עכשיו״ → ״הורדה לקובץ״.
   - לחלופין, קובץ הגיבוי שנוצר בהעברה: `yoman-full-backup-2026-11-21.json`.
2. באפליקציה: עוד → דוח התאמת נתונים וגיבוי → ״ייבוא קובץ גיבוי״.
   - אפשר גם להשתמש ב-`IMPORT_ON_START` או ב-`npm run import -- backup.json`.
3. בודקים בדוח ההתאמה שאין הפרשים.

## התקנה באייפון
פותחים את הכתובת ב-Safari → כפתור השיתוף → ״הוספה למסך הבית״.

## בדיקות
```bash
BACKUP=/path/backup.json bash test/run-all.sh   # כל הבדיקות: תהליך מלא באייפון ובמחשב + כל יכולת בנפרד
```
