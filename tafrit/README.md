# תפריטי פרו

אפליקציית תזונה אישית בעברית (PWA, מימין לשמאל), שנבנתה לשימוש ביד אחת באייפון. פותחים בבוקר, נשקלים, בוחרים מה לאכול ומקבלים המלצות להמשך היום.

## מה יש בה
- **היכרות אישית**: שאלון של 17 מסכים קצרים. אפשר לחזור ולתקן, וההתקדמות נשמרת. בכניסה חוזרת מוצגים הנתונים הקיימים לאישור, עם תאריך העדכון.
- **כמה אני שורף וכמה לאכול**:
  - הוצאה במנוחה לפי Mifflin–St Jeor.
  - הוצאה יומית כטווח (±10%).
  - יעד קלוריות מעוגל ל-50.
  - חלבון: טווח ויעד בגרמים, וחלוקה לארוחות.
  - ״איך חישבת לי?״ פותח כל שורה בחישוב, את המקור ואת הקישור אליו.
  - אימונים לא נספרים פעמיים, וצעדים מעל 3,000 מחושבים בנפרד.
  - כש-BMI ≥ 30 מוצג משקל הייחוס שבו השתמשנו לחישוב החלבון.
- **מאגר מזון אמיתי**:
  - 4,508 פריטים ממאגר התזונה הלאומי של משרד הבריאות, עם משקלי יחידות מידה (ביצה S/M/L/XL, פרוסה, גביע, כף).
  - סימון ברור של יבש / מבושל / מסונן / נא.
  - מוצר אישי לפי תווית האריזה, השלמה מ-USDA FoodData Central, מתכון ביתי (כולל שמן ורטבים, לפי החלק שנאכל), מועדפים וארוחות קבועות.
- **היום שלי**:
  - שלוש פעולות: ״אבחר בעצמי״, ״בנה לי יום שלם״ ו״הצע לי את הארוחה הבאה״. ארוחה נעולה נשארת כמו שהיא.
  - לכל ארוחה: תכננתי / אכלתי / ערוך כמות.
  - נספר רק מה שסומן ״אכלתי״. אם תכננת 200 ג׳ ואכלת 150, נספרים 150.
  - החלפת רכיב אחד מראה מיד מה השתנה.
  - ״יש לי בבית…״ מציע ארוחה מהמוצרים שכתבת.
- **שקילה**:
  - שקילה אחת לכל תאריך לפי שעון ישראל. אם כבר יש שקילה לאותו יום, מוצעת עדכון. אפשר לתקן שקילה ישנה, וכל שינוי נשמר בהיסטוריה.
  - ממוצע ראשון–שבת: סכום השקילות חלקי מספר השקילות בפועל (״5 מתוך 7 שקילות״).
  - גרף עם קו מגמה, ושבוע שעדיין לא הסתיים מסומן כ״בתהליך״.
- **סיכום שבועי והתאמה**:
  - ממוצע משקל, שינוי בק״ג ובאחוזים, וממוצע קלוריות וחלבון מימים שסומנו ״מתועד במלואו״ (עם מספר הימים).
  - שאלה קצרה על רעב, אנרגיה וביצועים באימון.
  - הצעת שינוי מתונה (100–200 קק״ל) רק אחרי פער עקבי בשבועיים. יעד קודם מוצג מול מוצע, והשינוי חל מתאריך שבוחרים.
  - בדיקת חלבון נפרדת.
- **מלווה התזונה שלי (עוזר AI)**:
  - Claude עם כלים שמחשבים בקוד מול המאגר, כך שהכמויות בצ׳אט זהות ליומן.
  - כרטיסי ״הוסף לתכנון״.
  - ״על מה מבוססת ההמלצה?״ מפריד בין מקור מחקרי לבין החלטת תוכנה.
  - בלי מפתח עובד ״מצב בסיסי״ שמזהה את הבקשות הנפוצות: שקילה, מה לאכול, ממה שיש בבית, כמה נשאר, למה.
- **מצבים רפואיים**: במחלת כליה, הפרעת אכילה או הריון האפליקציה לא מחשבת יעד בעצמה. מזינים את היעדים שקבעו דיאטן או דיאטנית, וממשיכים להשתמש ביומן.

## הפעלה
```bash
cd tafrit
npm install
npm start                # http://localhost:8080
```
- דרישה: Node.js 22.5 ומעלה. מסד הנתונים הוא SQLite מובנה, ונשמר בתיקייה `data-local/` או ב-`DATA_DIR`.

| משתנה | תפקיד |
|---|---|
| `ANTHROPIC_API_KEY` | מפעיל את המלווה דרך Claude (`claude-opus-5-5`). בלעדיו המלווה עובד במצב בסיסי |
| `TAFRIT_MODEL` | לא חובה. החלפת המודל |
| `APP_PASSWORD` | לא חובה. מוסיף מסך סיסמה, מומלץ כשהאפליקציה פתוחה לאינטרנט |
| `USDA_API_KEY` | לא חובה. מפתח חינמי ל-FoodData Central; בלעדיו נעשה שימוש ב-DEMO_KEY המוגבל |
| `DATA_DIR`, `PORT`, `PUBLIC_URL` | תיקיית נתונים, פורט, וכתובת https (לעוגייה מאובטחת) |

**פריסה**:
- Docker: `docker build -t tafrit . && docker run -p 8080:8080 -v tafrit-data:/data -e ANTHROPIC_API_KEY=... tafrit`
- Render: יוצרים Web Service מסוג Docker עם Root Directory `tafrit`, ודיסק קבוע ב-`/data`.

**התקנה באייפון**: Safari → שיתוף → ״הוספה למסך הבית״.

## מאגר המזון
`data/foods.json` נבנה ע״י `npm run build-foods`, שמושך את המאגר מה-API הרשמי של data.gov.il.

## בדיקות
```bash
npm test          # בדיקות יחידה: חישובים, ממוצע שבועי, התאמה, מאגר, החלפה, ולולאת הכלים של Claude מול שרת מדומה
npm run e2e       # מסלול מלא באייפון 13 (Playwright)
```
המסלול המלא בודק:
1. שאלון, כולל חזרה, תיקון ושמירת התקדמות.
2. יעדים ומקורות.
3. ארוחת בוקר מהמאגר (2 ביצים L).
4. אכלתי חלקית ו״ערוך כמות״.
5. הצעת ערב, הצעה ממה שיש בבית, ו״בנה יום״ עם ארוחה נעולה.
6. החלפת רכיב.
7. שקילה דרך הצ׳אט כשכבר יש שקילה לאותו יום.
8. סיכום שבועי.
9. שמירה אחרי פתיחה מחדש.
10. יעד חדש מתאריך.

## מבנה
- `shared/` — כל החישובים, משותפים לשרת ולדפדפן: `nutrition` (יעדים), `foods` (מאגר ויחידות), `planner` (המלצות והחלפה), `weights` (ממוצעים), `adjust` (סיכום שבועי), `sources` (מקורות והחלטות תוכנה).
- `server/` — HTTP ו-API (`index.js`), אחסון (`db.js`, `store.js`), כלי המלווה (`tools.js`), Claude (`ai.js`), USDA (`usda.js`).
- `public/` — הממשק (JS בלי בנייה, CSP קשיח).
